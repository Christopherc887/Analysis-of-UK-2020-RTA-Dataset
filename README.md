# UK Road Traffic Accident Analysis (2020)

An analysis of the UK's 2020 road traffic accident data using SQL and Python, including Random Forest and Gradient Boosting classification.

## Project questions

- What patterns are present in the accident records?
- Which variables are associated with the modelled outcome?
- How well do the classification models perform on held-out data?

## Tools and methods

- SQL
- Python
- pandas
- Random Forest Classifier
- Gradient Boosting Classifier
